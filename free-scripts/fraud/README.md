# 💵 Fraud

{% embed url="https://youtu.be/DK9RdQP_lGg" %}

## Github Download: [\[Click Here\]](https://github.com/pulsepk/pl_fraud)

A **free FiveM fraud/scam script** where players set up a card skimming operation near ATMs. Deploy a laptop, printer, and generator, fuel the generator, then complete a hacking minigame to clone ATM cards and collect the reward.

Powered by [pl\_lib](https://github.com/pulsepk/pl_lib) for automatic framework, inventory, target, and notification detection.

***

## Features

### 💳 Card Skimming Operation

Players place three physical props — a **laptop**, a **printer**, and a **generator** — near an ATM. After fuelling the generator, a hacking minigame starts. Success yields a `clone_card` item worth a configurable reward.

### 🎮 Configurable Minigame

Supports **datacrack** (default), `ps-ui-circle`, `ps-ui-maze`, and `ps-ui-scrambler`. Switch minigames from config with one line.

### 🛒 Built-in Item Shop

An NPC shop spawns in the world selling all required fraud items. Location, items, and pricing are fully configurable.

### 🔧 Object Gizmo Support

Enable `Config.UseObjectGizmo = true` to use the [object\_gizmo](https://github.com/DemiAutomatic/object_gizmo) resource for precise item placement instead of the built-in placement controls.

### 🚨 Police Dispatch Integration

Optional dispatch alert on fraud activity. Auto-detected by pl\_lib — supports ps-dispatch, aty-dispatch, Quasar Dispatch, Rcore Dispatch, and more.

### ⚙️ Framework & Inventory Compatible

Works with **ESX**, **QBCore**, and **Qbox** out of the box via pl\_lib. Supports ox\_inventory, qb-inventory, and esx\_inventory.

### 🎯 Target System

Supports **ox\_target** and **qb-target** — auto-detected, no config needed.

### 🔔 Notification System

Auto-detected via pl\_lib. Supports ox\_lib, esx\_notify, okokNotify, wasabi\_notify, brutal\_notify, and more.

### 🌐 Multi-Language Support

Available in **English**, **Spanish**, **German**, **French**, **Italian**, and **Turkish**.
